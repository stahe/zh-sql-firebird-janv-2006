    8. 为 [Firebird] 安装并使用 ODBC 驱动程序

    8.1. 安装驱动程序

    市场上有许多数据库。 为了统一在 MS Windows 下的数据库访问，微软开发了一个名为 ODBC（Open DataBase Connectivity）的接口。该层将各数据库的特性隐藏在标准接口之下。 在 Windows 系统中，有许多 MS 驱动程序可简化数据库访问。以下是安装在 Windows 机器上的部分 ODBC 驱动程序示例：

    基于这些驱动程序的应用程序无需重写代码即可使用任何数据库。ODBC驱动程序位于应用程序与SGBD之间。 应用程序与驱动程序 ODBC 之间的交互是标准的。如果更换 SGBD，则安装新版本 SGBD 的驱动程序 ODBC，应用程序保持不变。

    [Firebird] 下载页面（第 2.1 段）中的 [firebird-odbc-provider] 链接可访问 ODBC 驱动程序。 安装后，该驱动程序将显示在已安装的 ODBC 驱动程序列表中。
